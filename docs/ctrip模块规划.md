## 一、项目定位

- 类型：轻量级旅游 Web 平台
- 核心：攻略内容 + 行程规划 + 机票 / 酒店比价 + **旅游盲盒**
- 目标用户：年轻人、学生、自由行爱好者、性价比用户
- 业务模式：内容种草 → 行程规划 ~~→ 比价预订~~ → 盲盒玩法

## 二、前台功能模块

### 1. 首页模块

- 全局搜索：目的地 / 景点 / 攻略搜索 / **AI智能搜索**
- 轮播 Banner、热门目的地推荐
- **盲盒专区（固定醒目入口）**
- 特价机票、特价酒店推荐
- 攻略精选、热门行程推荐

### 2. 目的地 & 攻略模块

- 目的地基础信息：景点、美食、玩法、最佳旅行时间
- UGC 攻略（*旅游UGC大数据是用户上传至网上的与旅游相关的内容，用户包括游客、政府推广部门以及旅游企业。旅游UGC大数据记录了海量的旅游行为与互动，优势主要表现在样本量大、时效性强、无研究者介入干扰、对象的无反应性，尤其在对普通人群的心里、观念、行为的研究中具有重要的价值，但缺陷是数据质量往往难以保证。旅游UGC大数据分为文本数据、图片数据、视频数据*）、游记、点评、收藏
- 按行程天数分类：1-3 天、3-5 天、5 天以上
- 景点清单、旅行避坑指南

### 3. 行程规划模块

- 自由创建行程：添加天数、景点、交通、住宿
- 拖拽排序、导出、分享
- 目的地智能路线推荐
- 一键关联机票 / 酒店预订

### 6. 旅游盲盒模块（核心功能）

- 盲盒类型：

  - 机票盲盒（固定出发 → 随机目的地 / 日期）
  - 目的地盲盒（随机城市 + 旅行套餐）
  - 酒店盲盒（城市内随机高性价比酒店）


- 核心功能：购买、开盒、分享、规则查看、退款说明

- 运营支持：限时活动、学生特惠、限量库存

## 三、后台管理模块

1. 用户管理：用户列表、信息查看、状态管理
2. 内容管理：目的地、攻略、景点、内容审核
3. 产品管理：机票 / 酒店接口配置
4. 订单管理：订单查询、状态同步
5. **盲盒管理：类型、价格、库存、规则、活动配置**
6. 运营管理：轮播图、弹窗、推荐位、数据概览

## 六、开发流程

### 1.前端开发阶段（5–7 天）

1. 页面搭建：PC + 移动端响应式（UniApp）

2. 核心功能：

   - 首页、搜索、目的地攻略
   - 行程规划（拖拽、导出）
   - 机票 / 酒店列表、比价
   - **盲盒：盲盒列表 → 购买 → 支付 → 开盒 → 结果页**

3. 用户中心、我的订单、我的盲盒

4. 输出：可交互前端页面

------

### 2.后端开发阶段（5–7 天）

1. 用户体系：注册 / 登录 / Token

2. 内容接口：攻略、目的地、景点

3. 订单接口、支付接口

4. 盲盒核心接口：

   - 盲盒列表
   - 创建订单
   - 支付回调
   - 开盒逻辑
   - 我的盲盒记录

5. 机票 / 酒店对接、比价逻辑

6. 后台管理接口

7. 输出：完整 API + 后台系统
